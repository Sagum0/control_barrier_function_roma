# 2026-07-23

## Summary

ArUco 큐브의 세 면 pose를 직접 이용해 base 기준 ZED 두 대의 6-DOF pose를 측정하는 도구를 추가했다.
측정 결과는 YAML로만 전달하고, 별도 ROS2 Humble 패키지가 세 static TF를 한 번에 발행하도록 구성했다.
순수 수학 셀프테스트, Fusion config SDK readback, YAML 왕복, ROS2 패키지 정적 검증을 통과했다.

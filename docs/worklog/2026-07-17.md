## PLAN03 orbit 수식 부호 정정 (plan-free, 사용자 지정 1줄)

- **문제**: Claude 가 PLAN03 "2단계 스펙"에 적은 orbit 회전식이 잘못돼, orbit 의 좌우가 front 와
  **거울**로 나왔다. 검증 수치: `orbit(az=0,el=0) = (+2.0, 3.0)` vs `front = (-2.0, 3.0)`.
  plan 이 주장한 "`el=0` → front 와 유사" 성질이 성립하지 않았다. codex 는 스펙대로 정확히
  구현했고, **틀린 것은 plan 의 스펙**이었다.
- **조치**: `scripts/zed_fusion_viz.py` `_project_world` 의 orbit 분기에서 `h` 부호만 뒤집었다.
  `h = -x*sin(az) + y*cos(az)`  →  **`h = x*sin(az) - y*cos(az)`** (1줄).
  CLAUDE.md 의 "사용자가 지정한 한 줄은 plan 없이 허용" 예외로 처리했다.
- **검증** (`zed` env python, cv2 사용 — codex 는 cv2 부재로 못 했던 부분):
  - `orbit(az=0, el=0)  == front` → `(-2.0, 3.0)` **일치**.
  - `orbit(az=90, el=0) == side`  → `(1.0, 3.0)` **일치** (부수 효과로 side 정합까지 얻음).
  - `top/front/side` 투영식 **불변** 확인 — 기존 뷰 동작 보존(사용자 명시 요구).
  - top/front/side/orbit **4개 뷰 실제 렌더** + 빈 검출(0 bodies) 모두 예외 없음.
  - `python3 -m py_compile scripts/zed_fusion_viz.py` 통과.
- **남은 것**: `--view orbit` 라이브 육안 확인(`j/l/i/k/u` 키)은 사용자 `zed` env 몫.
- PLAN03 본문은 `status: done` 이라 이력으로 그대로 두었다(수식 정정 기록은 이 worklog 가 SoT).
